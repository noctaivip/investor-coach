# Investor Coach

Investor Coach — русскоязычное PWA для ускоренного обучения профессиональному общению с инвесторами.

## Основные режимы

- **Coach** — главный адаптивный тренер;
- **Учить** — полный словарь терминов;
- **Тесты** — проверка понимания с разбором ошибок;
- **Живая речь** — объяснение терминов голосом;
- **Pitch** — голосовая тренировка инвестиционного рассказа;
- **Инвестор** — симуляция реальной встречи;
- **7 дней** — интенсив;
- **30 дней** — профессиональный курс.

## Как работает Coach

Coach не заставляет перечитывать один и тот же текст на соседних шагах.

Для каждого понятия используется последовательность:
1. короткое объяснение только при первом знакомстве;
2. извлечение смысла из памяти;
3. узнавание термина в конкретной ситуации;
4. понимание, зачем инвестор задаёт этот вопрос;
5. выбор сильного профессионального ответа;
6. голосовой ответ своими словами;
7. возврат слабого понятия позже по интервальному повторению.

В основе используются retrieval practice, spaced repetition, interleaving, worked examples и immediate feedback.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## AI и точная голосовая транскрипция

Frontend можно разместить на GitHub Pages. Секретный API key нельзя хранить в браузере.

Backend из папки `backend/` разворачивается отдельно как Cloudflare Worker.

Worker secret:

```bash
npx wrangler secret put OPENAI_API_KEY
```

Укажите `ALLOWED_ORIGINS` для вашего сайта.

## PWA

После публикации по HTTPS приложение устанавливается через кнопку «Установить приложение». На iPhone/iPad: Safari → Поделиться → На экран «Домой».
