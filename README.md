# Investor Coach

Investor Coach — русскоязычное PWA для ускоренного обучения профессиональному общению с инвесторами.

## Основные режимы

- **Coach** — главный адаптивный тренер;
- **Учить** — полный словарь терминов;
- **Тесты** — проверка понимания с разбором ошибок;
- **Живая речь** — объяснение терминов голосом;
- **Pitch** — голосовая тренировка инвестиционного рассказа;
- **Инвестор** — симуляция реальной встречи;
- **7 дней** — интенсив;
- **30 дней** — профессиональный курс.

## Как работает Coach

Coach не заставляет перечитывать один и тот же текст на соседних шагах.

Для каждого понятия используется последовательность:
1. короткое объяснение только при первом знакомстве;
2. извлечение смысла из памяти;
3. узнавание термина в конкретной ситуации;
4. понимание, зачем инвестор задаёт этот вопрос;
5. выбор сильного профессионального ответа;
6. голосовой ответ своими словами;
7. возврат слабого понятия позже по интервальному повторению.

В основе используются retrieval practice, spaced repetition, interleaving, worked examples и immediate feedback.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## AI и точная голосовая транскрипция

Frontend можно разместить на GitHub Pages. Секретный API key нельзя хранить в браузере.

Backend из папки `backend/` разворачивается отдельно как Cloudflare Worker.

Worker secret:

```bash
npx wrangler secret put OPENAI_API_KEY
```

Укажите `ALLOWED_ORIGINS` для вашего сайта.

## PWA

После публикации по HTTPS приложение устанавливается через кнопку «Установить приложение». На iPhone/iPad: Safari → Поделиться → На экран «Домой».


## Learning Engine 10.1
Coach теперь адаптирует частоту повторения к степени освоения: ошибка возвращает термин раньше, уверенное знание — позже. Для уже знакомых терминов добавлен отдельный шаг переноса знания в собственную фразу для реальной встречи с инвестором.


## Professional Learning Engine 11.0

Эта версия усиливает именно профессиональное обучение:

- термин считается освоенным не только по карточкам/SRS, а по трём слоям: знание, применение в Coach и качество живой речи;
- Professional Readiness объединяет знания, тесты, голосовую речь и Investor Simulator;
- Investor Simulator имеет три режима: первая встреча, инвесткомитет, due diligence;
- AI оценивает семь отдельных навыков: прямота ответа, ясность, доказательность, цифры, терминология, работа с риском, структура;
- следующий вопрос строится по слабому месту, недоказанному тезису или противоречию ответа;
- симуляция формирует итог встречи и рекомендует следующий тип тренировки;
- Coach и симулятор используют одну персональную модель навыков, поэтому приложение постепенно выбирает более полезную практику.

AI-backend остаётся необязательным для базового офлайн-обучения, но динамический Investor Simulator и профессиональная голосовая оценка требуют backend из папки `backend`.


## Adaptive Placement & Retention v12

- входная диагностика из 12 вопросов;
- автоматический выбор маршрута 7 / 14 / 30 дней;
- отдельный показатель удержания знаний;
- один рекомендуемый следующий шаг на главной;
- удержание считается только когда термин имеет и интервальное закрепление, и практическое mastery;
- маршрут можно вручную поменять в Coach.


## Adaptive Brain Engine v13

Для каждого термина приложение различает пять разных проблем: понимание смысла, самостоятельное воспроизведение, применение, свободную речь и долговременное удержание. Следующее упражнение выбирается по типу пробела, а не только по числу ошибок.

Также фиксируются устойчивые путаницы между похожими терминами. При повторной путанице Coach специально противопоставляет эти понятия вместо очередного чтения определения.


## Investor Meeting Exam v14

Финальный экзамен — 10 последовательных голосовых ответов без учебных подсказок. AI сохраняет ключевые утверждения и цифры из ответов, строит follow-up по слабому/недоказанному месту и отмечает реальные противоречия. После завершения формируется итог по семи навыкам; результат экзамена входит в Professional Readiness.

Экзамен требует подключённого AI backend. Итог является внутренней учебной оценкой приложения, а не внешней профессиональной сертификацией.


## Measurable Proficiency v15

- baseline автоматически фиксируется после входной диагностики;
- Professional Readiness и удержание показываются как «до → сейчас»;
- показывается изменение семи профессиональных навыков;
- Investor Meeting Exam сохраняется как контрольная точка;
- добавлена повторная проверка удержания уже изученного материала;
- история контрольных точек хранится локально для пилотного тестирования.

Внутренние баллы приложения — учебные метрики, а не независимая профессиональная сертификация.

## Pilot Evidence Engine v17

Добавлен минимальный контур доказательства результата обучения:
- фиксация baseline перед пилотом;
- фиксация результата после Investor Meeting Exam;

Это не внешняя сертификация. Для корпоративных claims об эффективности необходимо провести пилот на реальных пользователях по заранее определённой методике.


## Release Candidate Hardening v18

- добавлен внутренний стек навигации для корректного шага назад внутри PWA;

## End-to-End QA Fixes v19

В release QA обнаружены и исправлены реальные проблемы:

1. Удалён второй, конфликтующий Back-stack из v18. В приложении снова один источник истории: `pushAppHistory / restoreHistoryState`. Это устраняет двойные history entries и нестабильный Android Back.
2. После завершения входной диагностики baseline теперь сразу отображается на экране, без необходимости дополнительного перехода.
3. «Проверка удержания» стала настоящей retrieval-проверкой из 8 вопросов без карточек. Раньше кнопка только пересчитывала накопленные баллы, что не являлось новой проверкой памяти.
4. Обновление Service Worker больше не должно принудительно перезагружать приложение посреди Coach, экзамена, ускоренной сессии или голосовой записи. Новая версия активируется в безопасный момент.
5. Добавлен `scripts/qa_release.mjs` с инвариантами release-сборки.

Версия PWA: 19.0.0.


## Live Investor Dialogue v20

- Раздел «Инвестор» переработан в мобильный живой диалог вместо перегруженной двухколоночной панели.
- Сценарии «Первая встреча / Инвесткомитет / Due diligence» сохранены, но теперь работают внутри одного conversation-first интерфейса.
- Голосовая запись в production AI режиме пишется через MediaRecorder до нажатия «Отправить»; битрейт повышен до 96 kbps.
- Серверная транскрипция получает контекст встречи и словарь VC/SaaS терминов; это улучшает распознавание чисел и профессиональной терминологии.
- Следующий вопрос AI по-прежнему формируется из предыдущего ответа, слабого места или противоречия.
- Добавлен компактный блок терминов живой речи и конкретный разбор ответа.


## Final Voice Note Flow v22

Живой диалог теперь использует знакомую схему голосового сообщения:
1. нажать «Записать ответ»;
2. говорить без отправки;
3. нажать «Остановить»;
4. запись остаётся готовой;
5. нажать «Отправить» отдельно.

Также можно нажать «Отправить» прямо во время записи — приложение сначала корректно завершит файл, затем выполнит транскрипцию и AI-анализ. На мобильном композер закреплён над нижней навигацией.


## Network & Session Reliability v24

- AI-анализ имеет timeout и один повтор для временных 408/429/5xx ошибок.
- Транскрипция имеет timeout и одну повторную попытку; готовая голосовая запись не удаляется при transient-сбое.
- `/readyz` используется как лёгкая проверка доступности production AI.
- Исправлено завершение встречи по локальному лимиту вопросов: итоговый meeting report теперь формируется даже если модель не успела вернуть `session_complete=true`.
- В живом диалоге отображается компактное состояние AI backend.


### v24 QA note

Автоматический Chromium mobile-flow в текущей сборочной среде не выполнялся: sandbox блокирует навигацию headless Chromium к `127.0.0.1` и `file://` с `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому mobile UI необходимо дополнительно проверить на реальном Android/iPhone перед внешним пилотом. Статические PWA-ресурсы, JavaScript, backend, manifest, learning data и release-инварианты проверены автоматически.


## Pilot Data Integrity v25

- Прогресс теперь сохраняется через ограниченный и аварийно-устойчивый persistence layer, чтобы рост AI history не приводил к потере состояния из-за quota localStorage.
- При уходе приложения в background создаётся checkpoint текущего состояния.
- Незавершённая Investor-сессия сохраняет историю и отображает статус продолжения после повторного открытия.
- Запуск новой Investor-встречи безопасно останавливает старую голосовую запись и очищает временный audio state.
- Добавлена функция JSON-экспорта учебного прогресса для пилотной диагностики/резервной копии данных.


## Pilot Instrumentation v26

Приложение локально измеряет реальное использование учебного контура:
- активные дни;
- ответы в Coach;
- AI-разборы речи;
- ответы в Investor Dialogue;
- запуск Investor Meeting Exam;
- проверки удержания;
- Professional Readiness «старт → сейчас».

Кнопка «Скачать отчёт» формирует JSON для анализа пилота. В pilot instrumentation не сохраняются тексты голосовых ответов и сами аудиозаписи — только тип учебного события, баллы и технические учебные метаданные. Данные никуда автоматически не отправляются.
